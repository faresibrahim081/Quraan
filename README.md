# 📖 Quran Kareem Web App

A modern and responsive **Quran Kareem web application** built with **Next.js**, providing an easy and beautiful way to **read and listen to the Holy Quran** with multiple reciters and narrations.

The project also includes access to **Islamic live streaming channels** such as _Sunnah Channel_ and _Hadith Channel_.

---

## ✨ Features

- 📚 **Read the Holy Quran** with a clean and user-friendly interface
- 🎧 **Listen to Quran recitations** from multiple reciters
- 🎙️ Supports **different Riwayat (narrations)**
- 🔍 Easy navigation between Surahs and Ayat
- 📡 Watch **Live Streaming**:
  - قناة السنة النبوية
  - قناة الأحاديث النبوية
- ⚡ Fast performance and optimized loading
- 📱 Fully responsive design (Mobile / Tablet / Desktop)

---

## 🛠️ Tech Stack

This project is built using modern frontend technologies:

- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **Context api**
- **TanStack React Query**
- **API Integration** for Quran recitations & content
